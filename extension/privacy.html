CPI RESOURCE STUDIO · PUBLIC BETA

Privacy, in plain language.

Effective 4 November 2026. This policy covers version 0.5.1 of the independent CPI Resource Studio Chrome extension.

What the extension processes

When you activate it, the extension reads the current tenant hostname, integration-flow path, resource names and resource contents to display and edit your current flow. XML samples, generated schemas and resource drafts are processed in memory in your tab.

Where your data goes

No publisher server, analytics, advertising, tracking, remote conversion service or AI API is included. XML conversion runs locally. Saving or uploading sends the resource content and filename to the SAP tenant you are currently using through its existing signed-in interface. SAP and your organization's policies govern that tenant's processing.

The extension does not request cookies, passwords, API keys, browsing history, or persistent all-sites access. Its activeTab and scripting permissions let it run on the tab you explicitly activate. It shares the tenant page's JavaScript environment to interact with SAPUI5 and Ace, so data there is accessible to that page and other scripts running in it.

Local files, clipboard and retention

Open XML reads a file you select. Download writes a generated XSD through Chrome's normal download flow. Copy writes the generated XSD to your clipboard when you request it. The extension does not use persistent extension storage. In-memory drafts disappear when the page reloads or closes; downloaded files, clipboard data and saved tenant resources remain until managed through their respective applications.

Your control

Activate only on tenants you trust. You can disable or remove the extension in Chrome at any time. Removal does not delete files or resources you previously saved. The extension does not deploy integration flows.

Feedback

The extension does not send diagnostic data or email automatically.
