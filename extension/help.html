GET STARTED

A little help for your daily CPI work.

Open a signed-in SAP Cloud Integration tenant. On supported SAP-hosted Design and Monitor pages, the Studio toolbar appears automatically. You can also open tools from the Chrome extension icon.

Resource Editor

Open an integration flow, choose a resource and edit it in one workspace. Use the arrows to switch files or select Compare side by side to view two resources.

Save changes saves through CPI, including other pending flow edits. Nothing is deployed.

XML → XSD

Paste or open sample XML, enter a schema filename and preview the generated XSD. Review inferred types and optional fields, then choose Generate & save to CPI. The resource list refreshes after a successful upload.

Flow Inventory

Scan deployed interfaces and review them in package order. Interfaces remain listed even when source or target headers are missing. Choose the fields you want before exporting Excel or CSV.

Source: SAP_Sender or Sender. Target: SAP_Receiver or Receiver. Differing alias values are flagged. Dynamic expressions are not evaluated.

Naming Review

Choose SAP suggestions or upload project rules as JSON, PDF or Word .docx. Confirm patterns extracted from documents, review each proposed name and select only the changes you want.

Review works in Open and Edit modes. Apply enters CPI Edit when available. Use native CPI Save to persist the draft. Live review refreshes every five seconds while open, preserving typed suggestions and selections and pausing during apply.

Why does a suggestion say “Needs context”?

A step’s configuration does not always reveal its business purpose. Add your own meaningful purpose before applying a generic suggestion. The tool does not execute scripts or infer hidden business logic.

What should I do if a tool cannot save or apply?

Read the displayed error, check your CPI edit permissions and flow lock, and confirm the correct flow is open. Refresh suggestions if the flow changed. Save or copy unsaved drafts before reloading the tenant page.

Can I upload any PDF or Word document?

Use a text-based PDF or Word .docx with clear naming patterns. Scanned PDFs need text recognition first; legacy .doc files must be converted. Review extracted rules before activating them.
